# 動物健康管理アプリ（リポジトリ名: AniMediRec）

保護施設・動物病院・多頭飼育の現場向けの、個体ごとの健康記録アプリです。

## このリポジトリには2つのバージョンがあります

| バージョン | 場所 | 特徴 |
|---|---|---|
| **プロトタイプ版** | `index.html` | サーバー不要。ブラウザを開けばすぐ動く単一ファイル。データはリロードで消える（デモ用） |
| **クラウド版** | `public/` | Firebase（無料枠）でログイン・複数端末同期・永続保存に対応 |

卒業制作としての本実装は **クラウド版 (`public/`)** です。
セットアップ手順は [`docs/SETUP-FIREBASE.md`](docs/SETUP-FIREBASE.md) を参照してください。
利用量が無料枠内であれば**維持費0円**で運用できます（ただしCloud Storageの都合上、
Blazeプランへのアップグレード＝クレジットカード登録は必要です。予算アラートの
設定手順も上記ドキュメントに含めています）。

## クラウド版の機能

- 施設ごとのログイン（施設コード＋メールアドレス＋パスワード、管理者/職員/閲覧のみの権限）
- 個体管理番号（重複チェック付き）
- 複数端末での自動保存・リアルタイム同期（オフラインでも記録可能、復帰時に自動送信）
- 個体・記録の論理削除とゴミ箱（復元可能）
- 記録の日付順ソート（時系列が崩れない）
- 体重の単位を個体ごとに kg / g で選択可能
- CSV出力（個体一覧・記録）、JSONバックアップ（個体単位・施設全体）、印刷用カルテ
