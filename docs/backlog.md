# バックログ（未実装・未選定の候補）

このファイルは **upsert 専用**。候補の増減・選定結果が変わったら書き換える。
実装した項目はここから削除し、`docs/specs.md`へ記載する。

## 既知の負債（優先度高）

- **ネイティブダイアログ (`confirm()`/`prompt()`) が複数箇所に残っている**
  - `confirmDeleteAnimal()`（個体削除の確認）
  - `deleteLogRecord()`（記録削除の確認）
  - `editWeightRecord()` / `deleteWeightRecord()`（体重の編集・削除確認）
  - CLAUDE.md MANDATORYルール9「ダイアログ・メッセージボックスは自前実装を使う」に
    未対応。自前の確認モーダル・入力モーダルへの置き換えが必要。
- **一覧の「⚠️要観察」バッジが即時更新されない**
  - 記録を追加・変更した個体の`_warn`は、その個体の詳細画面を開いたときにしか
    再計算されない（`updateWarnFlag()`）。一覧に戻った時点では古いまま、というケースがある。
  - 対策候補: 記録の追加・編集・削除の保存タイミングで、都度`_warn`を計算して
    書き込む（read一発追加で済むはずなので無料枠への影響は小さい見込み）。

## 未実装（当初の仕様検討〈docs/SPEC-v2.md〉で挙げたが今回は着手していない）

- **監査ログ**: 「誰が・いつ・何を変更したか」の操作履歴画面。現状は各ドキュメントに
  `createdBy`/`updatedBy`はあるが、それを一覧できる画面がない。
- **記録・体重個別のゴミ箱UI**: 現在ゴミ箱画面は個体のみ対象。記録・体重は論理削除
  フィールド(`deletedAt`)自体は実装済みだが、復元するUIが無い
  （Firebaseコンソールから手動で`deletedAt`を消すことでのみ復元可能）。
- **本格的なPDFカルテ**: 現状は`window.print()`によるブラウザのPDF保存機能を利用する
  簡易版のみ。体重推移グラフの埋め込みや、「通院用サマリー(直近2週間の異常のみ)」
  モードは未実装。
- **パスワードリセット導線**: Firebase Authのメール送信によるリセット機能をUIに
  出していない（コンソールから手動リセットは可能）。
- **施設設定画面**: 施設名・施設コードの変更、施設の削除（廃業時の対応）は未実装。
- **マイクロチップ番号・鑑札番号などの追加識別情報**: `docs/SPEC-v2.md`②で
  候補に挙げたが、個体フォームには未追加。
- **体重の急変警告・目標体重レンジ**: `docs/SPEC-v2.md`⑦で候補に挙げたが未実装。
- **前回比の表示**（体重の増減％など）: 同上。
